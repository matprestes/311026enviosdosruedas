# Invariantes de Diseño

- **Colores:**
  - Azul Eléctrico: `#0950F6` (Tope de oscuridad; no usar negros ni grises neutros).
  - Amarillo Vial: `#FFEC01` (CTA, acentos, max 15%).
  - Blanco Puro: `#FFFFFF` (Fondo de página y tarjetas).
- **Sombras:** Teñidas con `rgba(9, 80, 246, ...)` o `rgba(255, 236, 1, ...)`.
- **Componentes:** Usar `DoubleBezelCard` y `CTANestedPill`.
